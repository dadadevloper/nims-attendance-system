# NIMS Student Attendance System (Java backend)

Files: Server.java (Java backend), index.html (HTML + CSS + JavaScript front end)

## Run
1. Install a JDK (version 11 or newer).
2. In this folder run:  java Server.java
3. Open http://localhost:8080

Data is saved in db.json next to Server.java.
Other devices on the same Wi-Fi can open http://<your-computer-IP>:8080

Logins: admin/admin123, teacher/teacher123, mustafa/1234 (same for the other students)
To reset all data: stop the server and delete db.json.
